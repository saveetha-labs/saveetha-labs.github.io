## 🌌 About the Project

Saveetha Labs is a **premium, student-driven open-source platform** that provides curated learning resources, lab programs, and study materials for engineering students at Saveetha University. Built with a cinematic "Premium SaaS" aesthetic inspired by Apple Vision Pro, Linear, and Vercel — featuring glassmorphism, soft glows, and smooth animations.

> **✨ Core Philosophy:** Democratize access to quality educational resources through open collaboration. Every repository is student-curated, peer-reviewed, and 100% free.

### 🏗️ Architecture

```
saveetha-labs.github.io/
├── index.html          # Main landing page (hero, projects, search, chatbot)
├── docs.html           # Full documentation & course catalog
├── 404.html            # Cinematic space-themed error page
├── favicon-16x16.png   # Favicon assets
├── favicon-32x32.png
└── knowledgebase.txt   # Complete master metadata index
```

## 🚀 Getting Started

### Prerequisites

Absolutely **zero dependencies**. Just a modern web browser.

- 🌐 Chrome / Edge / Firefox / Safari (latest 2 versions)
- 📝 Any text editor (VS Code recommended)
- 🔧 Optional: [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for hot reload

### Local Development

```bash
# 1. Clone the repository
git clone https://github.com/saveetha-labs/saveetha-labs.github.io.git

# 2. Navigate to the project
cd saveetha-labs.github.io

# 3. Open index.html directly in your browser — or
#    use a simple HTTP server (recommended):

#    Python 3
python -m http.server 8080

#    Node.js (if installed)
npx serve .

# 4. Visit http://localhost:8080
```

## 🤝 How to Contribute

We **love** contributions from students, faculty, and open-source enthusiasts! No contribution is too small.

### Quick Start

<div align="center">

| Step | Action | Command |
| :--: | :----- | :------ |
| **1** | 🍴 Fork the repo | Click **Fork** button on GitHub |
| **2** | 📥 Clone your fork | `git clone https://github.com/YOUR-USERNAME/saveetha-labs.github.io.git` |
| **3** | 🌿 Create branch | `git checkout -b feature/your-feature` |
| **4** | ✏️ Make changes | Edit files, add resources, fix bugs |
| **5** | 💾 Commit | `git commit -m "Add: brief description"` |
| **6** | 📤 Push | `git push origin feature/your-feature` |
| **7** | 🎯 Open PR | Go to GitHub and click **Compare & pull request** |

</div>

### Contribution Ideas

- ⭐ **Star** repositories you find helpful
- 🐛 Report [issues](https://github.com/saveetha-labs/saveetha-labs.github.io/issues) you encounter
- 📝 Improve documentation and course notes
- 💻 Add lab programs and working code examples
- 🎨 Enhance UI/UX, fix responsive bugs
- 🔍 Add new courses or create skeleton repositories
- 📖 Write tutorials and usage guides

### For Course Repositories

Each course repository follows this standard structure:

```
COURSE-CODE-SubjectName/
├── README.md
├── Notes/
├── Code/
├── Lab-Exercises/
├── Assignments/
├── Question-Papers/
└── References/
```
